# GitHub Testing

This repository contains a collection of Python scripts designed to automate and test various workflows on GitHub using Selenium WebDriver.

## 🚀 Overview

The project simulates real user interactions with GitHub, including:

* Logging in and saving session cookies
* Navigating user profiles
* Accessing repositories
* Managing branches
* Performing repository actions (create, delete, edit, etc.)

It is intended for learning, experimentation, and automation testing purposes.

---

## ⚠️ Important First Step (Read This or Suffer Later)

Before running any script, you **must run ****`login.py`**** first**.

```bash
python login.py
```

This will:

* Open GitHub login page
* Allow you to log in manually
* Save your authenticated session as `github_cookies.pkl`

All other scripts depend on this cookie file to function.

If you skip this step, expect:

* Failed logins
* Broken flows
* General disappointment

---

## ⚙️ Requirements

* Python 3.x
* Google Chrome
* ChromeDriver (compatible with your Chrome version)
* Selenium

Install dependencies:

```bash
pip install selenium
```

---

## 🔐 Authentication

Authentication is handled using cookies stored in:

```
github_cookies.pkl
```

These cookies are:

* Generated by running `login.py`
* Reused by other scripts to bypass login

⚠️ Keep this file secure. It contains your authenticated session.

---

## 🧪 Sample Workflow

1. Run `login.py` to generate cookies
2. Run any automation script (e.g., `open_profile.py`)
3. Script loads cookies and logs in automatically
4. Performs actions like:

   * Opening profile
   * Accessing repositories
   * Managing branches

---

## ▶️ Running Scripts

```bash
python <script_name>.py
```

Example:

```bash
python open_profile.py
```

## 🧠 Key Features

* Automated login via cookies

* Modular scripts for different GitHub actions

## ⚠️ Limitations

* Some links and selectors are **hardcoded**

  * You may need to manually update them depending on:

    * Your GitHub username
    * Repository names
    * UI changes from GitHub
* GitHub UI updates can break element locators
* Dynamic element IDs may change between sessions
